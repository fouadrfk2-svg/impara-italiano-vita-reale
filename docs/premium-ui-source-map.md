## Curated exclusions

- Removed house, medal, pause, play and sparkle because no rendered UI uses them; they added cache entries without serving a user task.
- Grammar navigation used a calculator class with no mask or bundled SVG, so it rendered blank. It now uses the already sourced book-open-text asset.
- Reviewed Kenney's [UI Pack](https://kenney.nl/assets/ui-pack); the game-oriented control artwork does not fit this adult editorial interface, so none is included.
- Reviewed [Motion's vanilla animate()](https://motion.dev/docs/animate), [React Bits' catalog](https://reactbits.dev/) and [license](https://github.com/DavidHDev/react-bits/blob/main/LICENSE.md), [Animata's catalog](https://www.animata.design/components) and license description ([site](https://animata.design/)), and [Magic UI's catalog](https://magicui.design/docs/components). No new library/component is integrated: this plain HTML/CSS/JS app needs only one native progress-width transition for a real data change, and importing a library or adapting animated React/Tailwind components adds complexity without improving that task. No source code is copied from these catalogs.

## Previous commit audit

Retained: the consistent Phosphor family; removal of platform-dependent emoji from navigation, contexts, logout and audio controls; explicit completed/current/locked path states; the real-progress next-lesson card; and a stronger final completion action.

Removed: route-head, feedback and summary entrance keyframes; guest-card, unit-header and bottom-navigation lift effects. They repeat during navigation or add movement without communicating a new learning state. The single progress-fill transition remains because its width reflects actual completed lessons; it is disabled for reduced-motion users.
